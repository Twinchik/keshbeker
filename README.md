# Кешбекер

Кошелёк банковских карт с кешбеком по категориям. Статичный сайт на GitHub Pages, данные и вход через Supabase.

## Где что лежит

```
index.html            разметка страницы, подключает стили и скрипты
manifest.webmanifest  установка на телефон как приложение
css/style.css         весь дизайн
icons/                иконки приложения
js/config.js          адрес и публичный ключ Supabase
js/data.js            справочники, общие функции и состояние, поиск, магазины → категории (MCC)
js/wallet.js          кошелёк: отрисовка карт, перетаскивание, подсказки поиска
js/photo.js           обработка фото карты
js/shops.js           вкладка «Магазины» и карты лояльности
js/editor.js          редактор карты, корзина, уведомления
js/account.js         вход, синхронизация с Supabase, импорт/экспорт, запуск приложения
.github/workflows/    ежедневный пинг, чтобы бесплатный Supabase не засыпал
```

Скрипты из `js/` — обычные `<script>` без сборки. Они подключаются в `index.html` строго по порядку
и делят общие переменные, поэтому порядок тегов менять нельзя: `account.js` запускает приложение и идёт последним.
