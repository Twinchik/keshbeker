# Безопасность

- Клиент использует публичный ключ Supabase. Изоляцию строк должны обеспечивать RLS-политики для владельца через `auth.uid()`; фильтр `user_id` в клиенте их не заменяет. Политики базы не представлены в репозитории. Проверять их следует в отдельном окружении.
- Данные в localStorage доступны скриптам того же origin. Не добавляй туда номера карт, CVV и другие секреты. Для оформления и OCR используй изображения без платёжных реквизитов.
- Скриншот распознаётся локально. Внешняя аналитика текущей PWA получает события и поисковый текст. При работе с аналитикой исключай пользовательские данные из новых событий.
- Используй секреты GitHub Actions для учётных данных задач и ключей будущих сборок. Ключ service_role запрещён в клиенте и тестовых данных.
