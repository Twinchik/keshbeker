# Продукт

Кешбекер помогает выбрать карту для оплаты по предложениям кешбека. Пользователь создаёт кошелёк, вводит категории вручную или загружает скриншот и проверяет результат распознавания. Можно подготовить категории следующего месяца заранее.

Поиск принимает категорию, магазин или MCC. Результат зависит от указанных пользователем условий и справочника типичных MCC. Фактический MCC может отличаться у разных точек.

Вкладка «Магазины» хранит карты лояльности и показывает варианты для оплаты в магазине и доставки. Гостевой режим даёт начать с локального кошелька. Вход даёт синхронизацию между устройствами.
