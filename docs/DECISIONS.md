# Архитектурные решения

| Решение | Причина |
| --- | --- |
| Сохранить классические браузерные скрипты для PWA | Инфраструктура разработки подключается без изменения загрузки и поведения приложения. |
| Парсить JS/TS через Babel и хранить JSON по одному файлу на модуль | Поддержка TSX и точечных чтений, предсказуемые диффы и проверка в CI. |
| Загружать классические скрипты в отдельном контексте тестов | Можно тестировать реальные функции до выделения общего модуля для мобильного клиента. |
| Запускать smoke в локальном Chromium с блокировкой внешней сети | Для гостевого сценария достаточно локальных файлов и заглушки Supabase. |
