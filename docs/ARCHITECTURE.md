# Архитектура

`index.html` загружает классические скрипты в заданном порядке. Общий контекст браузера связывает состояние из `data.js`, интерфейс и адаптер хранения из `account.js`. Последний запускает приложение.

Редактор обновляет кошелёк и передаёт запись адаптеру хранения. Гость пишет в отдельный ключ localStorage. После входа адаптер пишет в Supabase, таблицу `cards` с колонками `id`, `user_id`, `data`, `updated_at`. Снимок повторно запрашивается при возвращении на вкладку и раз в минуту.

Скриншот проходит через Canvas и Tesseract.js в браузере. Текст парсится в категории, которые попадают в редактор. Модели OCR лежат в `ocr/`, движок и клиент Supabase загружаются с jsDelivr. Шрифты загружаются с Google Fonts. Аналитика интегрирована через Яндекс Метрику.

GitHub Pages раздаёт статические файлы. Манифест задаёт установку PWA, а сервис-воркер запрашивает свежий HTML при навигации. GitHub Actions отдельно поддерживает активность Supabase через `keep_alive`.

История и описание исходной поставки доступны в [первичном обзоре](../PROJECT_OVERVIEW.md).
