# Кешбекер — обзор проекта и описание файлов

## Для чего нужен проект

Кешбекер помогает решить, какой банковской картой выгоднее платить за покупку. Пользователь добавляет свои карты, указывает категории и проценты кешбека на текущий и следующий месяц. Категории можно ввести вручную или импортировать со скриншота банковского приложения. По названию магазина, категории или коду MCC приложение ищет подходящие предложения и сравнивает проценты. Во вкладке «Магазины» можно хранить карты лояльности и смотреть, какая банковская карта подходит для оплаты в выбранном магазине.

## Где работает и с чем связан

- **GitHub Pages** раздаёт статический сайт из репозитория [Twinchik/keshbeker](https://github.com/Twinchik/keshbeker). [Сайт Кешбекера](https://twinchik.github.io/keshbeker/) вернул HTTP 200 при проверке. Интерфейс работает в браузере и устанавливается на телефон как веб-приложение (PWA).
- **Supabase** отвечает за регистрацию, вход по почте и паролю, восстановление пароля и синхронизацию. Записи кошелька хранятся в таблице `cards`. Приложение запрашивает актуальные данные при возвращении на вкладку и раз в минуту. В гостевом режиме данные хранятся в браузере через `localStorage`.
- **GitHub Actions** по расписанию делает пробный запрос к таблице `keep_alive` в Supabase, чтобы база на бесплатном тарифе оставалась активной. Задачу можно запустить вручную.
- **Tesseract.js** распознаёт текст скриншота в браузере. Движок загружается с jsDelivr, а модели русского и английского языков лежат в репозитории.
- **Яндекс Метрика** собирает посещения, события интерфейса и поисковые запросы. **Google Fonts** поставляет шрифты Unbounded и Onest. Клиентская библиотека Supabase тоже загружается с jsDelivr.

Интерфейс написан на HTML, CSS и JavaScript. `index.html` подключает скрипты в фиксированном порядке, поскольку они используют общие функции и состояние. Последним запускается `js/account.js`. Сборка проекта не требуется.

По истории Git первые файлы появились 28 сентября 2026 года. 15 октября сайт разделили на отдельные файлы и добавили задачу для Supabase. Последние изменения в текущей копии датированы 16 ноября 2026 года и касаются первого запуска и импорта кешбека.

## Описание файлов

| Файл | Назначение |
| --- | --- |
| [README.md](README.md) | Краткое описание проекта и правила обновления CSS и JavaScript на опубликованном сайте. |
| [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md) | Этот обзор проекта, его сервисов и файлов. |
| [index.html](index.html) | Точка входа. Содержит разметку экранов входа, кошелька и магазинов, подключает стили, манифест и скрипты. |
| [css/style.css](css/style.css) | Оформление приложения, включая карты, формы, мобильную раскладку, анимации и цветовые темы. |
| [js/config.js](js/config.js) | Адрес проекта Supabase и публичный ключ для клиентского подключения. |
| [js/account.js](js/account.js) | Запускает приложение, управляет входом, регистрацией, восстановлением пароля, профилем, гостевым режимом и синхронизацией кошелька. |
| [js/data.js](js/data.js) | Содержит справочники банков, категорий, магазинов и MCC. Приводит данные карт к общему формату и ранжирует карты по запросу. |
| [js/wallet.js](js/wallet.js) | Отрисовывает кошелёк, показывает подробности карт и результаты поиска, подсказывает запросы и позволяет менять порядок карт перетаскиванием. |
| [js/editor.js](js/editor.js) | Открывает редактор карты и категорий на текущий и следующий месяц. Управляет внешним видом карты, сохранением, корзиной и восстановлением. |
| [js/photo.js](js/photo.js) | Обрабатывает фотографию для оформления карты: находит углы, выравнивает перспективу и корректирует изображение. |
| [js/scan.js](js/scan.js) | Распознаёт банковские скриншоты и извлекает из текста категории кешбека и проценты. |
| [js/shops.js](js/shops.js) | Управляет вкладкой «Магазины», карточками магазинов и картами лояльности. Подбирает банковскую карту для оплаты или доставки. |
| [js/theme.js](js/theme.js) | Переключает светлую и тёмную темы и сохраняет выбор. Содержит общие анимации, всплывающие подсказки и регистрацию сервис-воркера. |
| [js/install.js](js/install.js) | Показывает кнопку установки там, где браузер её поддерживает, и инструкцию по добавлению на экран «Домой» на iOS. |
| [js/onboarding.js](js/onboarding.js) | Показывает приветствие, проводит по интерфейсу, помогает добавить первую карту и предлагает варианты названий категорий. |
| [js/metrics.js](js/metrics.js) | Подключает Яндекс Метрику и регистрирует просмотры разделов, действия и поисковые запросы. |
| [manifest.webmanifest](manifest.webmanifest) | Задаёт название, иконки, цвета и режим отдельного окна для установленного веб-приложения. |
| [sw.js](sw.js) | Сервис-воркер. При переходе на страницу сначала запрашивает свежий HTML из сети. |
| [icons/icon-180.png](icons/icon-180.png) | Иконка 180×180 для добавления сайта на экран «Домой» на устройствах Apple. |
| [icons/icon-192.png](icons/icon-192.png) | Иконка 192×192 для вкладки браузера и установки веб-приложения. |
| [icons/icon-512.png](icons/icon-512.png) | Иконка 512×512 из манифеста, поддерживающая обрезку под форму значка системы. |
| [ocr/rus.traineddata](ocr/rus.traineddata) | Модель распознавания русского текста для Tesseract. |
| [ocr/eng.traineddata](ocr/eng.traineddata) | Модель распознавания английского текста для Tesseract. |
| [.github/workflows/supabase-keep-alive.yml](.github/workflows/supabase-keep-alive.yml) | Ежедневно обращается к Supabase. Использует секреты репозитория и повторяет запрос при ошибке. |
