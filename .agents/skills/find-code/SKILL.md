# find-code

Выбери область в docs/CODE_MAP.md. Выполни npm run code:find -- NAME или npm run code:find -- --file PATH. Сверь строки через rg и прочитай нужный диапазон. Для классических скриптов ищи вызовы по имени и сверяй порядок загрузки в index.html.
